## CMS-ის ფაქტობრივი გადამოწმება

Payload 3.92.1-ში Local API-ის `overrideAccess`-ის ნაგულისხმევი მნიშვნელობა
ინსტალირებული წყაროთი შემოწმდა: `true`. საჯარო წამკითხველში მისი აშკარა გამორთვა
ამ ვერსიისთვის აუცილებელია. ახალი ვერსიის დოკუმენტაციიდან სხვა default არ გადმოგვიტანია.

რეალურ Payload ოპერაციებზე შემოწმდა:

- ხელით შერჩეული რესურსების თანმიმდევრობა;
- ადრე გამოქვეყნებული, შემდეგ Draft-ად გადაყვანილი კავშირების გამორიცხვა ყველა slot-იდან;
- ცარიელი კურირებული სიის შემთხვევაში მაქსიმუმ სამი საჯარო რესურსის fallback;
- `home`-ის გამოქვეყნებული ვერსიისა და უფრო ახალი Draft-ის გამიჯვნა;
- Preview-ის რეჟიმში Draft ვერსიის წაკითხვა;
- გამოქვეყნებიდან მოხსნილი Post-ის გაქრობა საჯარო და ID-ებით შერჩეული ძიებიდან;
- ქეშირებული დოკუმენტის წამკითხველით Draft-ის მიუწვდომლობა.

არსებული homepage/API ტესტები დამატებით ამოწმებს ქართულ ძიებას, კატეგორიას,
საძიებო ინდექსის საჯარო წაკითხვის აკრძალვასა და ანონიმური ჩაწერის შეზღუდვებს.
CMS-ის `filterOptions` Local API-ზეც ვალიდირდება: სატესტო home ჯერ მოქმედი კავშირებით
იქმნება, შემდეგ დაკავშირებული Post იხსნება გამოქვეყნებიდან. ვალიდაცია არ შესუსტებულა.

Posts/Pages-ის არსებული autosave/Preview კონტრაქტი და published-only შერჩევა სწორია;
კონტენტის არქონა ხარვეზად არ ჩათვლილა. Categories/Media/Users-ის მოქმედი სქემები და
წვდომის წესები უცვლელია. მედიის ატვირთვისა და რეალური login/reset წერილის ახალი
HTTP სცენარი ამ ეტაპზე არ გაშვებულა.

გარეთაა; აპლიკაციის dependency არ დამატებულა. კლასტერში მხოლოდ სატესტო Post/Page
მონაცემები შეიქმნა და გასუფთავდა; Clinical Library-ის რესურსები არ ჩატვირთულა.

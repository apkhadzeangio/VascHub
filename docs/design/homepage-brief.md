სწავლასა და პროფესიულ აქტივობაში ჩართვის შესაძლებლობა. ნავიგაცია ექვს მიმართულებას
ინარჩუნებს; შესვლა და პირადი კაბინეტი ცალკე მოქმედებებია. სტატიკური მაჩვენებლები,
მოგონილი პარტნიორები ან აკრედიტაცია არ გამოიყენება.

## გამოყენებული მიდგომები და წყაროები

Relume, Mobbin და v0 ამ სესიის დაკავშირებული აპების ძიებაში ვერ მოიძებნა.
გამოყენებულია მათი სამუშაო პრინციპები და საჯარო პირველწყაროები; მათი პროექტები
ან სერვისებით გენერირებული ფაილები არ შექმნილა.

- **Relume-ის მიდგომა:** სექციების პრიორიტეტები → wireframe → გამეორებადი ბლოკები → ვიზუალური კონცეფცია.
  ოფიციალური აღწერა: https://www.relume.ai/resources/docs/using-the-relume-figma-plugin
- **Mobbin-ის მიდგომა:** შესაბამისი პროდუქტების კონკრეტული UX პატერნების შედარება.
  Mobbin-ის დაცულ screens/flows ბიბლიოთეკაში შესვლა არ მომხდარა. იხილეთ ქვემოთ
  სამი საჯარო მაგალითი. ზოგადი მეთოდის წყარო: https://mobbin.com/
- **v0-ის მიდგომა:** არსებული კომპონენტები, responsive კომპოზიცია და დიზაინის ტოკენები.
  https://v0.app/docs/figma და https://v0.app/docs/design-systems-2

## შემოწმება და დარჩენილი შეზღუდვები

- SVG-ები შეიცავს რედაქტირებად `<text>` და ვექტორულ ელემენტებს; screenshot fill არ გამოიყენება.
- Desktop-ისა და Mobile-ის ქართული ტექსტები ვიზუალურად გადაიხედა PNG რენდერებზე.
- გადაფარვა, რომელიც პირველ მობილურ ვერსიაში გრძელ სათაურს ჰქონდა, გასწორდა.
- ტექსტის გაზომვის შემოწმებამ გარე საზღვრებში გადაცდენა ვერ აღმოაჩინა: `assets/layout-qa.json`.
- ძირითადი foreground/background წყვილების კონტრასტი მინიმუმ 4.5:1-ია: `assets/contrast-qa.json`.
- HTML-ის DOM smoke check ამოწმებს ქართულ ძიებას, ცარიელ მდგომარეობას, Escape-ს,
  სამი რესურსის/ექვსი თემის არსებობასა და ძირითად labels/landmarks-ს.
- native dialog-ის focus trap და ბრაუზერის რეალური responsive განლაგება ამ გარემოში
  არ შემოწმებულა. DOM შემოწმება ბრაუზერულ ტესტად არ არის წარმოდგენილი.
- Figma-ის ცარიელ ფაილში გადასატანია wireframe, ორი ეკრანი, კომპონენტების მდგომარეობები,
  Auto Layout, native components/instances, shared styles/tokens და prototype connections.
  ამისთვის ჯერ Figma MCP-ის წვდომა უნდა აღდგეს.

## ასლების აღდგენა

რენდერების გენერაცია: `python docs/design/source/build_design.py`.

საერთო ტოკენები და component instances დამატებით უნდა შეიქმნას.

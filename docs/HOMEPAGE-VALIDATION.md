შემოწმებული აპის კომიტი: [`ae558013`](https://github.com/apkhadzeangio/VascHub/commit/ae558013afc27bc8af8e69546445ef9e1b113bb6).

ანგარიში და ქვემოთ მოცემული PNG-ები ამ კოდის ვერსიას აღწერს; შემდგომი დოკუმენტაციის
კომიტები აპის კოდს არ ცვლის. საჯარო ჰოსტინგი არ გამართულა.

ბრაუზერში შემოწმდა ცარიელი CMS, გამოქვეყნებული და Draft კონტენტი, სტატიის გვერდი,
390/768/1440 px განლაგება, გრძელი ქართული ტექსტი, გვერდისა და ტექსტის გადაცდენის არქონა,
ხატულის ჩატვირთვა და მინიმუმ 44 px მოქმედების სამიზნეები. შემოწმდა მენიუს გახსნა,
Tab/Shift+Tab ფოკუსის შეკავება, Escape, ფოკუსის დაბრუნება, scroll-ის აღდგენა და ბმულით დახურვა.
ასევე შემოწმდა ძიების Enter-ით გაგზავნა, შედეგი და ცარიელი შედეგი, წევრის სივრცის
მიუწვდომლობის განმარტება, footer-ის hover ტექსტისა და კლავიატურის focus-ის კონტრასტი.

რეალურ `/admin` ინტერფეისში შეიცვალა მთავარი სათაური და გამოქვეყნდა გვერდი;
ცვლილება ცალკე, არაავტორიზებულ ბრაუზერში გამოჩნდა. არსებული ადმინისტრირების ტესტებიც
წარმატებულია. Integration ტესტები დამატებით ამოწმებს Draft-ის დამალვას, გამოქვეყნების
გაუქმების შემდეგ არჩეული მასალის დამალვას, Search ინდექსის ანონიმური კითხვის აკრძალვას,
ანონიმური CMS ჩაწერის აკრძალვას, ღონისძიების URL-ის ვალიდაციას და საქართველოს თარიღის საზღვარს.

## რეალური ფუნქციები და CMS

მუშაობს მთავარი გვერდი, მობილური ნავიგაცია, თემიდან ძიებაზე გადასვლა და
გამოქვეყნებული სტატიების ძიება სათაურში, SEO აღწერასა და კატეგორიებში.
რესურსები, სასწავლო მასალა და სიახლეები რეალურ Posts ჩანაწერებს ხსნის.
ღონისძიების ცნობა ხსნის ადმინისტრატორის მითითებულ საჯარო ბმულს.

Pages-ის `home` ჩანაწერში რედაქტირდება შესავალი, სათაური, კლინიკური თემები,
გამორჩეული რესურსები, სასწავლო ბლოკი, ღონისძიებების ორი მოკლე ცნობა და ორი სიახლე.
Header/Footer globals-ის არსებული სანავიგაციო ბმულები შენარჩუნებულია.
კონტენტის დამატებისას საჯაროდ გამოსაჩენად საჭიროა Publish.
მართვისა და გაშვების დეტალები: [HOMEPAGE.md](HOMEPAGE.md).

საჯარო წევრობა, პროფესიული ანგარიშები, კურსების გავლა, ღონისძიებების რეგისტრაცია და
ცნობარი ამ ეტაპში არ შექმნილა. შესაბამისი მოქმედებები აჩვენებს მკაფიო განმარტებას;
წევრის შესვლა და პირადი კაბინეტი `/admin`-ს არ უკავშირდება.
ღონისძიებები და აკადემია მთავარზე წარმოდგენილია მოკლე ცნობით/სტატიით, სრული მოდულის გარეშე.

აღარ გვპირდება ჯერ არარსებულ კურსების/თვითშეფასების ფუნქციებს. გრძელი სათაურები და
რეალური მონაცემები გვერდის სიმაღლეს ცვლის; Figma-ის ფიქსირებული სიმაღლე არ დაგვიფიქსირებია.

ფაილის მფლობელობის შეცვლის შეზღუდვამ დაბლოკა. ბაზის, ბრაუზერისა და Docker-ის რეალური
შემოწმებები ამიტომ შესრულდა GitHub CI-ში; არცერთი საჭირო შემოწმება არ გამორთულა.
მიგრაცია შემოწმებულია იზოლირებულ ცარიელ ბაზაზე; რეალური მომხმარებლის მონაცემები

არსებული ელფოსტის console adapter და jobs/cron-ის შეზღუდვები უცვლელია.

## მოკლე გაშვება

ჩამოტვირთეთ `feat/homepage` ბრენჩი. [README](../README.md)-ის მიხედვით შეავსეთ `.env`
ცალ-ცალკე შემთხვევითი საიდუმლოებით და გაუშვით `docker compose up --build -d`.
Compose დაწყებისას ასრულებს მიგრაციებს. ლოკალური PostgreSQL-ის გამოყენებისას:

```bash
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm dev
```

მისამართებია `http://localhost:3000` და `http://localhost:3000/admin`.
პირველი ადმინისტრატორი იქმნება მხოლოდ README-ში აღწერილი `pnpm admin:create` გზით.
Integration/E2E ტესტებისთვის გამოიყენეთ ცალკე `_test` ან `-test` ბაზა.

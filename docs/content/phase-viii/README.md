[გადასახედი სრული ტექსტები](FIRST_RELEASE_GE.md) მოიცავს 3 სამეცნიერო სიახლეს, 2 ღონისძიებას და 1 პროფესიულ შესაძლებლობას. [კატეგორიებისა და ავტორის მიბმა](first-release.relationships.required.json) ჯერ უნდა შეივსოს რეალური CMS ID-ებით. [სარედაქციო მონაცემები](first-release.selection.json) შეიცავს სტატუსებსა და წყაროს მოცულობას.

## არსებული CMS-ის გამოყენება

[ინტეგრაციის ზუსტი გზა](CMS_INTEGRATION_GE.md) ეყრდნობა Posts, Categories და Pages/home.homepage ველებს. ახალი Collection, API Route ან კომპონენტი არ ემატება. Category ID-ების რუკაში null-ები განზრახაა: რეალური მნიშვნელობები არ გამოიგონოთ. სამეცნიერო ავტორები CMS Users-ის ავტორებად არ შექმნათ.

მიმდინარე მოცულობისთვის საკმარისია Admin-ში ახალი Posts მონახაზების ხელით შექმნა. JSON მასივი სტანდარტულ bulk-იმპორტს არ ნიშნავს; არსებული REST Create ერთი დოკუმენტის სხეულს იღებს. ამ ეტაპზე Draft-იც კი არ ჩაიწეროს Production-ში. პირველი პარტიის სტატუსი არის სარედაქციო QA შესრულებული, პასუხისმგებელი რედაქტორის შემოწმება და Preview — დარჩენილი.

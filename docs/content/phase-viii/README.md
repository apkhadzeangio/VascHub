29.10.2026-ის მდგომარეობით მომზადებულია 14 ქართული სამეცნიერო მიმოხილვა, 13 მომავალი ღონისძიება, 8 პროფესიული განვითარების ჩანაწერი და ოთხკვირიანი კალენდრის 20 პოზიცია. N08 შეჩერებულია გამომცემლის საბოლოო ვერსიის დაზუსტებამდე.

ყველა ახალი Draft-ის სათაური, Slug, SEO ველი, კატეგორია და ტექსტი ავტორიზებული პასუხით `draft=true` შემოწმებულია. Preview ექვსივეზე გაიხსნა; Preview-ის გამორთვის შემდეგ F01-ის მისამართზე გამოჩნდა 404. თავდაპირველი ცარიელი Post ID 1 ხელუხლებელია.

`scientific-news.json`, `events.json`, `opportunities.json`, `editorial-calendar.json` და საწყისი Draft სხეულები შენარჩუნებულია როგორც კვლევის/მომზადების წყაროები. მიმდინარე ჩატვირთვის სტატუსის წყაროა v1.3-ის ანგარიში და მისი JSON. v1.2-ის ინსტრუქციების თავში მითითებულია, რომ ქვემოთ მოცემული მოსამზადებელი მდგომარეობა ისტორიულია; „იმპორტი არ შესრულებულა“ მიმდინარე სტატუსს აღარ აღწერს. დარჩენილი 25 Draft სხეული სრულ ZIP პაკეტშია; საწყისი ექვსი Slug თავიდან არ ჩატვირთოთ.

პასუხისმგებელი სამედიცინო/სარედაქციო განხილვა და ცალკე გადაწყვეტილება გამოქვეყნებაზე ჯერ დარჩენილია. ავტორის არჩევითი CMS ველი ცარიელია; ჟურნალის ავტორები ბიბლიოგრაფიაშია. ახლო ვადები გამოქვეყნებამდე ხელახლა გადაამოწმეთ. N08 CMS-ში არ ჩატვირთულა.

ეს ბრენჩი მხოლოდ `docs/content/phase-viii/` დოკუმენტებს ცვლის. აპლიკაციის კოდი, main, Clinical Library, მთავარი გვერდი და ინფრასტრუქტურა ამ სამუშაოში უცვლელია. [PR #5](https://github.com/apkhadzeangio/VascHub/pull/5) რჩება Draft-ად და არ გაერთიანებულა.

### რას ფარავს ახალი ტესტები

- **`events-logic`** (15): თბილისის დღის საზღვარი (`21:00Z` → შემდეგი დღე), „დღეს“ = მომავალი, წინა დღე =
  ჩატარებული, არავალიდური/ცარიელი/ზღვარს გარეთა თარიღი → `undated` და არ ვარდება; ბმულების კლასიფიკაცია
  (`javascript:`, `data:`, `//host`, `/admin`, `/api`, ინტერვალი, ცუდი კოდირება, `?query`, პაროლიანი URL,
  უცნობი ლოკალური გზა — უარყოფილია); URL პარამეტრების უსაფრთხო წაკითხვა და round-trip; დალაგება;
  რაოდენობები; თარიღის ფილტრის ხილვადობა; გვერდები და ცარიელი შედეგი.
- **`events-data`** (12, რეალური `*_test` ბაზა): გამოქვეყნებული Post ჩანს, Draft და უკავშირო Post — არა;
  ტიპები განცალკევებულია; Post-ს არ აქვს თარიღი/ადგილი; კანონიკური URL-ით შერწყმა დუბლიკატის გარეშე;
  გარე ბმული; თარიღის გარეშე ცნობა = `undated`; Draft/არარსებული/ბიბლიოთეკის/უცნობი ლოკალური სამიზნე
  ბარათს არ ქმნის; კატეგორიის გარეთა გამოქვეყნებული Post-ის ცნობა ერთხელ ჩანს; **მთავარი გვერდის
  უფრო ახალი Draft ვერსია საჯარო სიაში არ აღწევს**; Post-ის გამოქვეყნების მოხსნა მაშინვე ცვლის სიას;
  კატეგორიების არარსებობისას — პატიოსანი ცარიელი სია; ანონიმური წვდომის წესები.
- **`events-components`** (6, jsdom): „თარიღი დასაზუსტებელია“, გასული ღონისძიების ნიშანი, გარე ბმულის
  `target`/`rel`, „პროფესიული განვითარება“ ≠ „ტრენინგი“, loading (`role=status`, `aria-busy`),
  error (`role=alert`, „ხელახლა ცდა“ იძახებს `reset`-ს და შეცდომის ტექსტს არ აჩვენებს).
- **e2e** (15): პირველი გვერდი, Draft-ის არარსებობა HTML-ში; თარიღი/ადგილი მხოლოდ დადასტურებულზე;
  ტიპის ფილტრი და რაოდენობები; ძიება + ტიპი მისამართში და reload-ის შემდეგ; გვერდები, ფილტრების
  შენარჩუნება, `?page=99` → ბოლო გვერდი; თარიღის ფილტრი; უსაფრთხო ბმულები; ცარიელი შედეგი;
  **კლავიატურა** (Tab → ბარათის ბმული, ერთი გაჩერება ბარათზე, Enter); GET ფორმა; **ადმინის სესია + Preview
  cookie Draft-ს არ აჩვენებს** (დამტკიცებულია, რომ ადმინი Draft-ს API-ში ხედავს, `/events`-ზე კი — არა);
  განლაგება **390 / 768 / 1440**: ჰორიზონტალური გადაფარვის გარეშე, 1 / 2 / 3 სვეტი; სრულიად ცარიელი მდგომარეობა.

## დაფიქსირებული დაკვირვებები

1. **JavaScript-ის გარეშე** `/events` „იტვირთება…“ მდგომარეობაში რჩება (Next.js streaming + `loading.tsx`);
   არსებული `/library`-ის `loading.tsx`-იც იგივე ნიმუშისაა. ამიტომ „JS-ის გარეშე მუშაობა“ არ არის
   დაცული ან დაპირებული (`README.md`, შეზღუდვა 5). თავდაპირველი no-JS ტესტი სწორედ ამიტომ ჩავანაცვლე
   GET ფორმისა და URL-მდგომარეობის შემოწმებით.
2. e2e-ის დროს სერვერის ლოგში ჩნდება `Error: The destination stream closed early` (ერთი და იგივე
   digest). ეს ემთხვევა მომენტებს, როცა ბრაუზერი მიმდინარე streaming პასუხს წყვეტს (სწრაფი ნავიგაცია /
   `request.get`). ტესტი ამის გამო არ ჩავარდნილა; მიზეზი უფრო ღრმად არ შემიმოწმებია.
3. ჩემი e2e იყენებს ერთადერთ `home` გვერდს, რომელსაც `homepage.e2e.spec.ts`-იც ქმნის — პარალელურად
   გაშვება არ შეიძლება (`workers: 1`; იხ. `integration-requests.md`, §6).
